# 腳本符號照文件

照某份文件（推導、報告、論文）實作公式時：

1. 變數名、存檔欄位、註解一律用該文件的符號，不自創名稱。
2. 公式照文件的最後一式逐項寫，不引入文件沒有的中介量。
3. 轉寫慣例：下標用 `_`（`W_o`、`s_oj`）；撇號用 `p`（s′ → `sp`、s″ → `spp`）；hat 用 `hat`（Î → `Ihat`）；上標名稱接在後面（D^LS → `D_LS`、D^Taylor → `D_Taylor`）；反矩陣用 `_inv`；粗體與否不區分。
4. 腳本頂部註解寫明依據的文件路徑與節次，方便逐式對照。
5. 文件沒有的量（迴圈索引、檔案路徑、繪圖常數）不受此限，照既有腳本慣例命名。
