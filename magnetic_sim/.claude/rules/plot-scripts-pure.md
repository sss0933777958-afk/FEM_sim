# 繪圖腳本只畫圖（強制讀取）

**使用者拍板（2026-09-11）**：**主流程負責校正並產出資料，繪圖腳本就是拿資料去畫。
繪圖腳本不干涉任何其他事情，純粹繪圖。**

當工作涉及：
- 寫 / 改任何 `plot/**` 底下的 `.m`，或任何檔名以 `plot_` 開頭的腳本
- 把一支「算完順手畫圖」的腳本放進 `plot/`
- 在繪圖腳本裡看到擬合、求解、讀 `.fld` / `.dat`、掃參數

**動手前先讀完此規則。**

相關規則：`calibration-shared-structure.md`（三段式分工的原始出處，2026-07-24 拍板）、
`matlab-output-layout.md`（`.mat` 落點）、`figure-style.md`（樣式）、`modify-existing-files.md`。

---

## 🔒 三層分工（唯一合法的資料流）

```
main/main.m + function/      校正 / 求解 → 產出 .mat        （唯一可以「算」的地方之一）
        ↓
utils/[<model>/]             後處理 compute：讀 .mat → 運算 → 存 .mat   （另一個可以「算」的地方）
        ↓
plot/<model>/                讀 .mat → 提取 → 畫圖 → 存 .png          （只准畫）
```

**`plot/` 底下的腳本只准做三件事**：`load` 一個既有的 `.mat`、從裡面取值、畫圖並輸出 `.png`。

## ❌ 繪圖腳本不准做的事

- 解任何線性系統 / 呼叫優化器 / 跑擬合（`\`、`lsqnonlin`、`fminsearch`…）
- 讀原始 FEM 場（`.fld` / `.dat`）或呼叫 `import_*` / `readmatrix` 去拿場
- 建取樣設計、跑收斂迴圈、掃參數階梯
- 產生新的 `.mat`（畫圖是終點，不是中繼）
- 呼叫 `model_config` 去拿幾何再自己算（要什麼就讓上游存進 `.mat`）

**判準**：把腳本裡所有 `plot` / `set` / `print` 的行拿掉之後，如果還剩下「在算東西」的程式碼，
那些程式碼就該搬去 `utils/<model>/`，並把結果存成 `.mat` 讓繪圖腳本去讀。

## 為什麼

1. **圖要能重畫而不重算。** 調字級、換刻度、改配色不該觸發一次重解；反過來，重算也不該
   靜默改掉圖的**內容**（2026-09-01 踩過：重跑 `plot_err_hist_shell` 連峰值都變了，
   因為快取的 N_c 與出圖當天不同，作者當場誤覆蓋了未提交的圖）。
2. **數字只有一個出處。** 同一個量在 compute 腳本與繪圖腳本各算一次，就會有兩個版本，
   而且不會有人發現它們分岔。
3. **`.mat` 自述、圖可追溯。** 圖的來源是某一個具名 `.mat`，回頭查得到它是哪次求解。

## 觸發片語

- 「畫圖 / 出圖 / 改這張圖」「這支放 plot 還是 utils」「繪圖腳本要不要重算」
- 你正要在 `plot/` 底下寫 `\`、`load` 一個 `.fld`、或 `save` 一個 `.mat` 時 → 停。

## 何時不適用

- 純粹為了**呈現**而做的輕量幾何運算（座標旋轉、單位換算、直方圖分箱、
  在既有資料上套一條 `polyfit` 當視覺參考線）—— 那是畫圖的一部分，不是產生新結果。
- `figures/paper_fig_plot/` 底下的論文圖腳本目前多支自己重建設計就地擬合，
  屬於既有債；動到哪支再依本規則收，不強制一次回溯。
- 一次性的探索腳本（`temp_code/scripts/`）—— 那裡本來就是算與畫混在一起的暫時區。
