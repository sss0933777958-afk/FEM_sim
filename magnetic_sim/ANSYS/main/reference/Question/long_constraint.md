# 龍飛最小電流問題的限制式從何而來

狀態：**待討論**（2026-11-07）。

## 1. 背景

龍飛（r_controller LUT）在每個位置、每個方向解最小電流的單位力問題時，另外加了一組不等式限制：

  min ‖Î‖²　s.t.　f̂(p, Î) = r̂，
  c_x = Î₁ + Î₂ ≥ 1/24，c_y = Î₃ + Î₄ ≥ 1/24，c_z = Î₅ + Î₆ ≤ 0

- Î_k 對應磁極 P_k；P1–P2、P3–P4、P5–P6 是三對互相垂直的對極，c_x、c_y、c_z 就是各對極的電流和（共模分量）。
- 1/24 是 LUT 的尺度（LUT 的力為 0.1）；換成單位力是 √10/24 = 0.1318。
- 論文只給出以 c 表示的限制式（Eq. 2.17），沒有推導；c_z ≤ 0 是從 LUT 的平台值反推出來的。

## 2. 問題

**這組限制是怎麼得到的？** 希望從中整理出推導思路：

- 為什麼取對極電流和 c 當限制變數，而不是其他量？
- 為什麼 x、y 兩對是 ≥ 1/24，z 這一對是 ≤ 0？三對極在幾何上等價，限制卻不對稱。
- 門檻 1/24 是怎麼來的（幾何、電流上限、或經驗調出來的）？
- 原本的目的是不是為了讓解平滑（固定在同一支），還是另有用途（例如避開某種電流配置），平滑只是副作用？

弄懂之後，才能判斷在含 bias（十八參數 ê）的模型下該怎麼推廣（見 `smooth_label.md`）。

## 3. 已知的效果（龍飛模型：R_norm 550 µm、理論 K_I、e = 0）

- **重現 LUT**：原點加上這組限制後，和 LUT 第一欄一致到 1.2e-4，r_controller 誤差圖完全重現（平均 0.1879 %、最大 0.405 %）。
- **讓解平滑**：全域最佳解（不加限制）在相鄰方向會跳支（例如 (45, 0, 0) µm、φ = 0° 時，Î₁ 在 θ ≈ 48°、306° 從約 −0.30 跳到 +0.28）；加了限制的解是連續的。
- **代價**：η = ‖Î_cons‖ / ‖Î_opt‖，在第一卦限 0:15:45 µm 的 64 點、6° 方向上平均 1.0802、標準差 0.1150、最大 2.16；34.0 % 的方向帶限制解就是全域解。
- **會失效**：在 (45, 45, 30) µm、φ ≈ −48° 到 −66° 的 46 個方向上，找不到同時滿足限制與單位力的解。
- **含 bias 時不保證平滑**：用十八參數 ê 時，同樣的限制下標籤有 81 處位置跳解，+45 µm 三軸點的最大力誤差到 13.8 / 13.7 / 10.7 %。
- **與 LUT 的差異**：擬合係數有 1565 / 1891 個方向和 LUT 一致到約 1e-6，其餘 326 個方向原因未明。

## 4. 可考慮的切入點（推測，待驗證）

1. **號誌**：Î 與 −Î 產生同一個力；要求 c_x、c_y 為正，等於替每個方向選定一個號誌，排除 −Î 那一支。
2. **共模分量**：理論 K_I 下總和 ΣÎ = 0 的方向沒有作用；對極電流和反映的是各對極沿軸向的共模，限制它可能是在選擇磁通從哪一對極「進出」的拓樸。
3. **z 的不對稱**：上下層極的排列（下層 0°、120°、240°，上層 60°、180°、300°）與 actuator frame 的定義可能讓 z 軸那一對在幾何上和 x、y 不同。
4. **門檻**：比較 c_x、c_y 在全域解上的分佈，看 1/24 是否剛好落在跳支發生的位置附近。
