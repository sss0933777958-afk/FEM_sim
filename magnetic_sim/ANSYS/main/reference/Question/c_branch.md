# 位置相依常數約束 c(p̄)：單層解在 ±90 µm 以外換支

狀態：**待討論**（2026-11-26）。接續 `c_pos.md`。

## 1. 背景

依 `c_position.pdf` 第 6 節，在每個位置 p̄_i，所有力方向共用一組 c(p̄_i) = [c_x, c_y, c_z]：

```
min  J = 1/2 Σ_j Σ_m { ‖δΦ̂(φ_j, θ_m; p̄_i)‖² + c_x² + c_y² + c_z² }
s.t. f̂_k = 1/4 CᵀL_kC + 1/2 CᵀL_k δΦ̂ + 1/4 δΦ̂ᵀL_k δΦ̂ = r̂_k(φ_j, θ_m)   (k = x, y, z，所有方向)
     c_x + c_y + c_z = 0
```

`c_pos.md` 的兩層做法（外層 c、內層每方向解 δΦ̂）在 60 µm 卡住。改成**單層**：c 與全部方向的 δΦ̂ 一起當變數（3 + 3 × 1742 = 5229 個），力方程式為等式限制（5226 條），fmincon `sqp` 一次求解，解析梯度。

設定：long2016、single 校正（N43，e = 0），方向 6° 網格不重複 1742 個（φ 0:6:354、θ 0:6:180、兩極各一次），不加權。位置為 x_a 軸上 11 點：原點、±30…±150 µm。原點起點用閉式解（c = a[1, 1, −2]，a⁴ = (8S_x + S_z)/(864N)，δΦ̂ = C⁻¹r̂/6），其餘點從同一半軸內一圈的點接力（c* 與 δΦ̂ 一起當起點）。

## 2. 結果

11 點都收斂，1742 個方向的力方程式殘差 ≤ 2×10⁻¹⁴：

| x (µm) | c* | J | 平均 ‖Φ̂‖ |
|---|---|---|---|
| 0 | [0.23308, 0.23308, −0.46616] | 567.82 | 0.568 |
| ±30 | [0.25287, 0.23520, −0.48808] | 588.23 | 0.577 |
| ±60 | [0.30933, 0.24140, −0.55073] | 652.89 | 0.608 |
| ±90 | [0.38609, 0.25249, −0.63859] | 778.40 | 0.664 |
| ±120 | [0.45967, 0.27095, −0.73062] | 960.90 | 0.738 |
| +150 | [0.53462, 0.29612, −0.83074] | 1178.62 | 0.819 |
| −150 | [0.53462, 0.29612, −0.83075] | 1185.97 | 0.822 |

−150 µm 的 J 比 +150 µm 大 7.35（照對稱應相同）：兩點都停在 exit 2，−150 µm 是較差的局部解。

原點比較：位置相依平均 ‖Φ̂‖ 0.5679，方向相依（每方向各自最佳 c，`cons_o.mat`，= 拉格朗日全域最佳）0.5049，比值 1.125。

## 3. 問題：±90 µm 以外 δΦ̂ 在方向上換支

以 6° 網格上相鄰兩方向 Φ̂ 的最大變化（六顆極取最大）檢查平滑：

| x (µm) | 0 | ±30 | ±60 | ±90 | ±120 | ±150 |
|---|---|---|---|---|---|---|
| 相鄰方向最大 \|ΔΦ̂\| | 0.037 | 0.045 | 0.050 | 0.254 | 0.364 | 0.332 |
| δΦ̂ 相鄰變化 > 0.1 的處數 | 0 | 0 | 0 | 62 | 162 | 206 |

- 0 ~ ±60 µm 平滑；±90 µm 以外出現跳動。
- 跳動只在**指向中心、背離最近極的那片方向**：+x 側的點在 −x 附近（φ ≈ 156°–204°、θ ≈ 48°–132°），−x 側的點在 +x 附近（鏡像）。離中心越遠範圍越大。
- 主要在 δΦ̂_x：+90 µm 沿 θ = 90°，φ = 168°、174°、180°、186°、192° 的 δΦ̂_x 為 −1.123、−0.915、−0.984、−0.915、−1.123（來回跳）。δΦ̂_z 在同一片方向也有 0 ~ 0.167 的小幅偏移，所以 Φ̂₅、Φ̂₆ 也有小凸起。
- 圖（+90 µm 六個 Φ̂）：`matlab/Force/Maxwell/figures/long2016_hexapole_halfcut/hexapole/isurf_pos_x90_I1..6.png`；−90 µm：`isurf_pos_xm90_I1..6.png`。Φ̂₂ 在 −x 附近突起到 0.6 以上、Φ̂₁ 同處下凹。

**推測原因**（未驗證）：收斂時 c 固定，每個方向的力方程式對該方向 δΦ̂ 是三條二次方程式，在這片方向可能有兩組實數解，兩組都滿足限制。J 只要求加總最小，沒有要求相鄰方向選同一組；sqp 從上一點的 δΦ̂ 接力，每個方向收斂到離起點較近的那組，相鄰方向因此交錯。這片方向正是 60 µm 兩層做法時一度無解的方向（物理上最難做，兩組解最接近）。

## 3.1 加行列式限制 det(∂F/∂δΦ̂) < 0（2026-11-26）

在單層最佳化每個方向加一條非線性不等式 det(∂F/∂δΦ̂) < 0（∂F/∂δΦ̂ 第 k 列 = ½ CᵀL_kT + ½ (TᵀL_kT δΦ̂)ᵀ；原點時 = 6 diag(c)，c 兩正一負 ⇒ det < 0，即原點延伸出的那一支）。1742 條，解析梯度；文件原本的限制不變；±90 µm 都從同軸 60 µm 的解起跑。

**det ≤ −10⁻⁸（成功）**：

| | 無 det 限制 | det ≤ −10⁻⁸ |
|---|---|---|
| c* | [0.38609, 0.25249, −0.63859] | [0.38609, 0.25241, −0.63851] |
| J | 778.40 | **769.79** |
| 平均 ‖Φ̂‖ | 0.6643 | 0.6616 |
| 相鄰方向最大 \|ΔΦ̂\| | 0.254 | **0.052**（與 ±60 µm 的 0.050 同級） |
| det > 0 的方向數 | 26 | 0（最大 det = −0.038） |

換支消失，J 反而變小：舊解在那 26 個 det > 0 的方向選到另一組根，是較差的局部解。±90 µm 完全對稱，exit 1，殘差 < 10⁻¹⁵，每點約 13 min。

剩下的現象：指向中心的方向（+90 µm 的 −x、φ = 180°、θ = 90°）Φ̂₂ 有一個尖峰，兩側相鄰差 ±0.034 到頂點直接反號。該方向 det = −0.038（不是 0），由隱函數定理解仍平滑，只是變化率 ∝ 1/det，峰頂曲率半徑小於 6° 網格，在網格上看起來像尖點（待以 1° 細網格確認）。

**det ≤ −0.1（有壞解）**：

| | det ≤ −10⁻⁸ | det ≤ −0.1 |
|---|---|---|
| +90 µm J | 769.79 | 770.84（只有 −x 一個方向碰到限制，峰頂相鄰差 ±0.034 → ±0.032，幾乎沒變） |
| −90 µm J | 769.79 | **2782.12**，c* = [1.0867, 0.1774, −1.2641]，平均 ‖Φ̂‖ 1.262（約正常的 2 倍） |
| exit / 時間 | 1 / 約 13 min | 2 / 35–40 min |

- −90 µm 照對稱應與 +90 µm 相同，卻停在很差的解：起點（−60 µm 解）有 61 個方向違反 det ≤ −0.1，sqp 為了滿足限制把 c 推到很遠，最後 exit 2（步長過小停止）。
- 同樣起點、同樣設定，+90 µm 正常、−90 µm 壞掉：表示 det 限制收緊後，可行域邊界附近的 sqp 對起點很敏感。
- 結論：det ≤ −0.1 沒有讓尖峰明顯變圓，還造成壞解；目前採 det ≤ −10⁻⁸ 的結果。

## 4. 可考慮的方向

1. **平滑懲罰項**（傾向先做）：J 加 (λ/2) Σ_相鄰 ‖δΦ̂_n − δΦ̂_m‖²；從小 λ 試，看跳支何時消失、J 與平均 ‖Φ̂‖ 增加多少。
2. **δΦ̂ 改用平滑方向函數**（如 2D 傅立葉係數為變數）：結構上連續，也是之後擬合要做的；代價是力方程式不再逐方向精確滿足。
3. **不等式限制把解綁在同一組**：需先弄清兩組解如何區分，在兩組交會處會退化。
4. 先驗證：在 +90 µm、固定 c* 時，−x 附近每個方向的力方程式有幾組實數解、sqp 選的是否為 ‖δΦ̂‖ 較小的那組。
