## 3. 換算

### 3.1 磁通與電流的關係

### 3.2 單位問題的代換

電流單位問題：Î_opt = argmin ‖Î‖² s.t. ÎᵀQ_kÎ = r̂_k，Q_k = K̄_IᵀL_kK̄_I。

- 限制式：Φ̂ᵀL_kΦ̂ = ÎᵀK̄_IᵀL_kK̄_IÎ = ÎᵀQ_kÎ，相同

**Φ̂_opt = K̄_I Î_opt**（嚴格相等）
