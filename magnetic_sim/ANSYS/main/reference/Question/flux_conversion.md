## 1. 背景

反模型文件把力模型寫成磁通的二次式，單位問題的變數是單位磁通 Φ̂：

f_k(p, Φ) = ᶠĝ_Φ ΦᵀL_k(p/ℓ̂, ê)Φ，Φ̂_opt = argmin ‖Φ̂‖² s.t. Φ̂ᵀL_kΦ̂ = r̂_k（k = x, y, z）

目前的全域最佳解（`nn_label_d15*.mat`，Gurobi）、ρ / 𝒞_f / κ_f、LS 與 NN 都是以電流為變數、最小化 ‖Î‖² 解出的。

## 2. 問題

改成以磁通表示後，Lagrange 最佳解要不要重解？

文件第 4 節寫「磁通（電流）平方和最小」，但 ‖Φ‖² 與 ‖I‖² 不是同一個目標，答案取決於選哪一個。

## 3. 分析

### 3.1 磁通與電流的關係

反模型文件 1.4 節：Φ = (N/R_a)K_I I = c K̄_I I，c = N κ₁₁ (6/5) / R_a。代入 b = ᴮĝ_Φ S Φ：

b = ᴮĝ_Φ c S K̄_I I = ᴮĝ_I S K̄_I I ⇒ ᴮĝ_I = c ᴮĝ_Φ，ᶠĝ_I = c² ᶠĝ_Φ

### 3.2 情況一：目標仍是最小電流，只改用磁通表示 → 不用重解

電流單位問題：Î_opt = argmin ‖Î‖² s.t. ÎᵀQ_kÎ = r̂_k，Q_k = K̄_IᵀL_kK̄_I。

代換 Φ̂ = K̄_I Î：

- 限制式：Φ̂ᵀL_kΦ̂ = ÎᵀK̄_IᵀL_kK̄_IÎ = ÎᵀQ_kÎ，相同
- 目標：‖Î‖² = ‖K̄_I⁻¹Φ̂‖²

K̄_I 可逆，Î 與 Φ̂ 一一對應，最小值點也一一對應：

**Φ̂_opt = K̄_I Î_opt**（嚴格相等）

縮放倍數一致：c K̄_I I = c K̄_I √(‖f_d‖/ᶠĝ_I) Î = √(‖f_d‖/ᶠĝ_Φ) K̄_I Î，與 Φ = √(‖f_d‖/ᶠĝ_Φ) Φ̂ 相同。

現有全域解可直接換算，不必重跑最佳化。

### 3.3 情況二：最小化 ‖Φ̂‖²（文件寫法）→ 要重解

最佳條件變成 (I₆ − Σ_k λ_k L_k)Φ̂ = 0，與電流版 (I₆ − Σ_k λ_k Q_k)Î = 0 不同，全域解、ρ / 𝒞_f / κ_f、LS、NN 都要重算。

**陷阱**：long2016 的 K̄_I（`calib_current_maxwell_axshN55_R150_eighteen.mat`）

- 每列和 0.040 ~ 0.053，接近 0
- 奇異值 1.13、1.04、1.03、0.911、0.905、**0.0466**（條件數 24.2），最小者的方向近似六極同號等量

這個磁通分量在 ‖Φ‖² 上便宜，換回電流卻要放大約 1/0.0466 ≈ 21 倍；且磁通守恆下六極總磁通應接近 0，實體上幾乎做不出。情況二應加限制 Σ_j Φ_j = 0，或把 Φ 限制在 K̄_I 的值域內。

`nn_train.m`、`ls_fit.m` 的 Q_k 把增益放在裡面：FH = √(ᶠĝ_I) K̄_I，Q_k = ᶠĝ_I K̄_IᵀL_kK̄_I。
