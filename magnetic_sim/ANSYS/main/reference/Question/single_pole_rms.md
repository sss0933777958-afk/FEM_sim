# 單極磁荷模型：讓各磁極形狀的 RMS 收斂曲線接近尖錐磁極

狀態：**待討論**（2026-11-22）。

## 1. 背景

以單磁荷模型（論文式 (2.12)）b = ĝ_c · s_c(p̄) · I 校正七個單極模型（`D:\Maxwell_sim\Single_pole`），磁荷在極軸上、深度 ℓ̂，I = 1 A。

- 校正點：兩端固定在極尖（0 mm）與 1 mm，p_i = [iΔx, 0, 0]ᵀ，i = 0 … N_c − 1，N_c = 1/Δx + 1，Δx 從 1 mm 往下調（論文座標磁極本體在 −x，模型座標相反）
- RMS = sqrt(J / (3·N_c))，J 為所有點、三分量的殘差平方和
- 收斂值：連續 10 階相對前一階變化 < 0.01 % 的第一階；所需點數：從該階起連續 10 階都在收斂值 ±10 % 內的第一階

只有 `cylinder_sharp_tip` 的 RMS 曲線單調下降、快速收斂；其他形狀有先升再降，或收斂 RMS 偏高。

## 2. 問題

**如何讓其他形狀磁極的 RMS 曲線也有尖錐磁極的表現？模擬設定上需要注意什麼？**

### 3.2 點數少時 RMS 由極尖的橫向場決定

模型在極軸上只產生 b_x；極尖（x = 0）的橫向場 b_⊥ 消不掉。N_c = 2 時 b_x 幾乎完全擬合，RMS ≈ |b_⊥(極尖)| / √6：

| 案例 | N_c = 2 的 RMS | 反推 \|b_⊥\| |
|---|---|---|
| cylinder_sharp_tip | 4.19 mT | ≈ 10.3 mT（直接讀到 b_y = 4.4、b_z = −9.3 mT，一致） |
| cylinder_half_sharp_tip | 26.9 mT | ≈ 66 mT（極軸落在剖面上） |
| Tip_cut_cylinder | 0.012 mT | ≈ 0.03 mT |

b_⊥ 大 → 點數少時 RMS 大、一路下降；b_⊥ 小 → 點數少時 RMS ≈ 0，先升再降。

### 3.3 取樣線是否通過 |b_x| 峰值

極尖前 0.1 / 0.25 / 0.5 / 1 mm 截面上（`.fld` 網格節點，不內插），取樣線的 |b_x| 占截面最大值：

| 案例 | 占比 | 峰值位置 |
|---|---|---|
| cylinder_sharp_tip | 100 / 99.8 / 100 / 98.9 % | 在取樣線上 |
| cylinder_half_sharp_tip | 99.2 / 99.8 / 98.0 / 96.7 % | 剖面下方 0.02–0.1 mm |
| Tip_cut_cylinder | 95.7 / 99.9 / 100 / 98.7 % | 近尖端偏到截面邊緣 |
| Tip_cut_half_cylinder | 89.5 / 93.3 / 98.3 / 97.3 % | 近尖端偏到截面邊緣 |
| Flat_pole_block | 75.7 / 91.1 / 97.4 / 99.8 % | 板的上緣稜角 |
| Step_pole_block | 88.7 / 84.3 / 81.9 / 88.3 % | 下層中段（z = −0.08 → −0.66 mm） |
| Tip_cut_flat_block | 63.5 / 86.2 / 93.2 / 98.7 % | 板的上緣稜角 |

- 錐形接近點源，模型前提成立
- 平板：磁通沿 3 mm 尖邊與稜角發出，屬線源；ℓ̂ 被推大（398、1464 µm）來模仿
- 階梯：原點放在台階轉角，取樣線一路偏離源中心，RMS 混進原點選擇的誤差

### 3.4 cylinder_sharp_tip 表現好的原因

旋轉對稱、R40 µm 球尖接近點源（ℓ̂ ≈ 49 µm，約在球心）、|b_x| 峰值在取樣線上；極尖只有網格不對稱造成的小 b_⊥，使曲線單調下降。

### 3.5 目前的模擬設定（`D:\Maxwell_sim\Single_pole\project`）

七個專案相同：`pole_tip`、`Sphere1` 網格 40 µm，其餘 4 mm；自適應最多 3 回、加密 15 %、能量誤差 1 %（全部收斂）；20 µm 規則網格匯出，取樣點三線性內插。四面體約 330 萬（錐形）、1100 萬（平板；平板曾記憶體不足失敗）。

## 4. 可考慮的方向

可以改的設定：

1. **極尖網格加密**：40 µm 等於球尖半徑；sharp tip 的 ≈ 10 mT b_⊥（理論上應為 0）可能來自網格不對稱。極尖前 0.2–0.3 mm 加局部空氣區，網格 5–10 µm。
2. **局部收斂**：全域能量誤差不保證極尖場準確；極尖區直接指定細網格，或提高自適應回數。
3. **沿極軸線匯出**：收斂時點距約 2–4 µm，比 20 µm 匯出網格細，等於在同一元素內重複取線性內插值；i = 0 落在鋼表面節點上。改用 Maxwell 沿極軸的線匯出，極尖點取空氣側或排除。
4. **平板加密範圍**：元素數已逼近記憶體上限，只加密尖邊前方，不整顆 `Sphere1` 加密。

不是模擬設定問題：

- 半切模型的大 b_z（剖面的物理）
- 平板的線源行為
- 階梯的原點（校正設定）：改到下層中點 z = −2.25 mm
