# LS 方法二的位置正規化：內部用 u = p/45 µm

狀態：**已實作**（2026-11-03）。

符號依 `reference/Force_model/Real_time_inverse model/flux_force_unit.pdf`（第 5.1 節、第 6.5 節）。

## 1. 背景

文件第 5 節規定位置以 p̄ = p/ℓ̂ 正規化，LS 的模型為

z_LS,m(p, φ_k, θ_j) = 𝒫(p̄)ᵀ D_m(φ_k, θ_j) 𝒫(p̄)，𝒫(p̄) = [x̄, ȳ, z̄, 1]ᵀ

展開成 10 個係數：𝒫ᵀD_m𝒫 = a(p̄)ᵀ d_m，a(p̄) = [x̄², ȳ², z̄², 2x̄ȳ, 2x̄z̄, 2ȳz̄, 2x̄, 2ȳ, 2z̄, 1]ᵀ。

## 2. 問題

單參數 ℓ̂ = 870.72 µm，訓練點 |p| ≤ 45 µm，所以 |p̄| ≤ 0.05，二次項約 0.0025。
以 p̄ 為變數時，常數項與二次項係數的尺度相差約 400 倍，方法二的 L-BFGS（126,100 個係數一起最佳化）收斂很慢。

例：p = 30 µm（只看 x 方向）

| 表示法 | 值 | 平方 |
|---|---|---|
| p̄ = p/ℓ̂ = 30/870.72 | 0.0345 | 0.0012 |
| u = p/45 = 30/45 | 0.667 | 0.444 |

## 3. 做法

方法二在最佳化時改用 u = p/(45 µm)，|u| ≤ 1，各係數尺度相近；算完再換回 p̄ 存檔。

兩者是同一組二次函數，只差係數縮放。因 x̄ = (45/ℓ̂) u：

d_m,p̄ = d_m,u × (ℓ̂/45)^(次數)，次數依 a 的順序為 [2 2 2 2 2 2 1 1 1 0]

即二次項乘 (ℓ̂/45)²、一次項乘 ℓ̂/45、常數項不變。換回後同一位置算出的 z 完全相同。

| | 計算時的位置變數 | 存檔的係數 d |
|---|---|---|
| 方法一 | p̄ = p/ℓ̂（QR 分解解 A d = y，封閉解） | p̄ |
| 方法二 | u = p/45 µm（L-BFGS），再換算 | p̄ |

模型照文件用 p̄；u 只是方法二的數值計算技巧，不影響結果。

## 4. 程式

`matlab/Force/Maxwell/utils/scripts/long2016_hexapole_halfcut/ls_fit.m`，`VAR = 'flux5'`、`MTD = 2`：
`Au = A_(P / A)`（u），`sc = (A / l_hat).^[2 2 2 2 2 2 1 1 1 0]'`，存檔 `d = x ./ sc`。
