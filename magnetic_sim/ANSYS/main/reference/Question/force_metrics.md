## 1. 磁通模型的現行定義

位置 p 處，電流到磁場的轉移是**線性**的：

b(p) = S(p) · ᴮĤ_I · I

- S(p)：3×6，各極電荷在 p 的形狀矩陣（S = r̄/‖r̄‖³ 堆疊）。
- ᴮĤ_I = ᴮĝ_I · K̄_I：6×6 電流轉移矩陣 [mT/A]。
- 對 T(p) = S(p)·ᴮĤ_I（3×6）做 SVD，得奇異值 σ₁ ≥ σ₂ ≥ σ₃：
  - **Efficiency index** 𝒞 = σ₁σ₂σ₃（圖上用 𝒞^(1/3)，單位回到 mT/A）
  - **isotropy** κ = σ₃ / σ₁（0~1，1 為各方向等效）
- 實作：`matlab/Flux/Maxwell/function/hexapole/solve_current.m` 的 `control_metrics`（逐節點 svd，取平均 / 最差值）；
  直方圖 `figures/paper_fig_plot/plot/plot_gain_iso_hist.m`。

## 2. 力模型的形式

磁珠受力 f = ½ · ᴹg_B · ∇(b·b)，代入 b = T(p)·I：

f_k(p) = Iᵀ Q_k(p) I，k = x, y, z，Q_k = ½ ᴹg_B · ∂_k(Tᵀ T)（6×6 對稱）

即電流到力是**二次型**（不可疊加），不是線性映射。校正輸出另有 ᶠĝ_I = ᴹĝ_B/(2ℓ̂)·(ᴮĝ_I)²、ᶠĤ_I = √(ᶠĝ_I)·K̄_I。

## 3. 問題

1. 磁通模型的 Efficiency index 與 isotropy 的**概念與計算方式**能否直接套用到力模型？
   （T 是線性映射才能用 SVD；力是電流的二次型，直接對 ᶠĤ_I 或某個 3×6 矩陣做 SVD 是否有物理意義？）
2. 若不能直接套用，有什麼數學方法能從力模型算出「這個 tweezer 產生力的效率」與「各方向產生力的均勻度」，
   作為與磁通 𝒞、κ 對應的指標？

## 4. 可考慮的方向（未驗證，僅供討論起點）

- **工作點線性化**：在某偏置電流 I₀ 附近，∂f/∂I = 2[Q_x I₀; Q_y I₀; Q_z I₀]（3×6），對它做 SVD 得 𝒞、κ；
  結果依賴 I₀ 的選擇。
- **單位電流下的最大可達力**：對每個方向 û，f_max(û) = max_{‖I‖=1} Iᵀ(Σ_k û_k Q_k)I = λ_max(Σ_k û_k Q_k)；
  效率取 f_max 在各方向的最小值（或可達力集合的體積），等向性取 min/max 比。
- 其他：可達力集合（力的 workspace / force ellipsoid）的幾何量、與電流限制（‖I‖∞ 或 ‖I‖₂）的關係。
