# 位置相依常數約束 c(p̄)：離開原點後力方程式無解、sqp 卡住

狀態：**待討論**（2026-11-25）。

## 1. 背景

依 `c_position.pdf`（位置相依常數約束推導，2026-11-24）：每個位置 p̄_i 所有力方向共用一組 c(p̄_i) = [c_x, c_y, c_z]，c_x + c_y + c_z = 0；給定 c，每個方向的 δΦ̂ 由三條力方程式決定

f̂_k = ¼ CᵀL_kC（偏壓項）+ ½ CᵀL_kδΦ̂（線性項）+ ¼ δΦ̂ᵀL_kδΦ̂（二次項）= r̂_k，

再取 J = ½ Σ_j Σ_m {‖δΦ̂‖² + c_x² + c_y² + c_z²} 最小的 c。

設定：long2016、single 校正（N43，e = 0，ℓ̂ = 870.72 µm）；位置為六軸殼層 6N_r + 1、N_r = 5、R = 150 µm（`nn_grid_axs5_r150.mat`，31 點）；方向為新定義（φ 方位角、θ 從 +z）6° 網格不重複的 1742 個。外層 c 用 fmincon `sqp`；程式在 `matlab/Force/Maxwell/utils/scripts/long2016_hexapole_halfcut/i_cons.m`（`CPOS`）。

## 3. 問題（+x 60 µm）

1. **以 30 µm 的 c 為初值，有方向的力方程式無實數解。** 內層每方向用 fmincon `sqp`（min ½‖δΦ̂‖² s.t. 力方程式）時，177 個方向不收斂，集中在 −x 周圍（φ 138°–222°、θ 48°–132°，約半角 42° 的錐），即從 +x 側往中心拉的方向。若依文件要求所有方向都有解，J 在起點無定義，fmincon 中止。
2. **把不收斂的方向排除在 J 外，sqp 卡住且「鑽漏洞」。** 排除後 J 不連續：c 一動，被排除的方向數在 293 ↔ 297 間跳，J 在 461.1 ↔ 463.4 間跳；sqp 的線搜尋一直被打回，步長縮到 10⁻⁶–10⁻⁷，9 步後原地打轉（每次 J 評估約 2.5 s，跑 5.5 min 後停掉）。同時 J 從 533 降到 461，是因為不收斂的方向從 177 增加到約 300：**被排除的方向越多 J 越小**，得到的 c 是放棄最多難解方向的 c，不是文件要的解。
3. **但 60 µm 存在所有方向都有解的 c。** sqp 線搜尋途中試到的幾組 c，1742 方向全部收斂：

| c | J |
|---|---|
| [0.3441, 0.3416, −0.6856] | 763.4 |
| [0.3976, 0.3303, −0.7279] | 826.8 |
| [0.4741, 0.3142, −0.7884] | 946.6 |

|c| 放大一些可讓 −x 那片方向也解得出來，代價是 J 明顯大於 30 µm 的 588。

另外在 +x 150 µm 以原點型的 c = [−0.44, 0.22, 0.22] 試算時，−x 方向的解剛好落在奇異點（Jacobian 條件數 10¹⁶），c 稍偏即無解：可行域離中心越遠越窄。

## 4. 可考慮的方向

1. **照文件（所有方向都要有解）**：任一方向無解則 J = Inf，起點改用可行的 c（例如 [0.344, 0.342, −0.686]），讓 sqp 在可行域內往 J 小的方向走；需確認 sqp 在可行域邊界（J 突然變 Inf）附近能否穩定收斂。
2. **先畫 60 µm 的可行域**：在 c_x + c_y + c_z = 0 平面上掃 (c_x, c_y)，標出所有方向都有解的區域與其中的 J 等高線，看最佳解是否在可行域邊界上。
3. **無解方向改用懲罰而非排除**：例如以力方程式殘差平方加權進 J，避免最佳化器靠讓方向無解來降低 J（偏離文件定義，需另行決定）。
4. **速度**：每次 J 要做 1742 次內層 fmincon（約 2.5 s）；可降低內層迭代上限、或用 Newton 先解、只對失敗方向用 sqp。
