# 非凸最小電流解的平滑化（含 bias）

狀態：**待討論**（2026-11-06）。

## 1. 背景

反模型要給出任意位置 p、任意方向 r̂(θ, φ) 的單位力電流 Î。三種近似函數都假設 Î 對方向與位置是平滑的：

- LS 雙線性內插：格點 **D**_m(φ_k, θ_j) 之間線性內插
- LS 三角函數：**D**_m(θ, φ) = Σ_l ψ_l(θ, φ) **C**_{m,l}（`Force_model/Real_time_inverse model/direction_fourier.pdf`）
- 神經網路：Î_NN(p, r̂; **W**)

以標籤損失 Σ_i Σ_j Σ_k ‖Î_LS(p̄_i, θ_j, φ_k) − Î_opt‖² 擬合時，參考解 Î_opt 必須平滑。

## 2. 問題

每點最佳解 Î_opt = argmin ‖Î‖²，限制條件 f̂(p, Î) = r̂，這是非凸問題。**全域最佳解在相鄰方向、相鄰位置之間會跳支**（Î 與 −Î 給同一個力，加上換支），平滑函數無法貼合。

龍飛（r_controller LUT）在最小電流問題上另加限制：

  c_x = Î₁ + Î₂ ≥ 1/24，c_y = Î₃ + Î₄ ≥ 1/24，c_z = Î₅ + Î₆ ≤ 0（LUT 尺度；單位力時為 √10/24 = 0.1318）

這組限制讓解固定在同一支、變成平滑的，但**不清楚它是怎麼推導出來的**：論文只給了限制式 Eq. 2.17，c_z ≤ 0 是從 LUT 反推的。

**加入 bias（十八參數的 ê）後，同樣的限制不再保證平滑**，部分位置與方向的力誤差到 14 %。

**問題：有沒有一種方法，能讓非凸最小電流問題的解平滑，而且在含 bias 的模型下也適用？**

## 3. 現有證據（龍飛模型：R_norm 550 µm、理論 K_I；第一卦限 0:15:45 µm 64 點；方向 6°）

最大力誤差 e_f，依序為原點 o 與 +45 µm 的 x、y、z 三軸點：

| 全域最佳解 | 逐方向二次式 | 219 % | 150 % | 150 % | 149 % |
| 全域最佳解 | 三角函數 N = 6 | 101 % | — | — | — |
| 帶限制 | 無擬合，只做方向內插 | 0.405 % | 0.686 % | 0.686 % | 0.405 % |

| 帶限制 | 三角函數 N = 6 | 11.5 % | — | — | — |
| 帶限制 + bias（ê 直接用、不換算） | 逐方向二次式，常數項固定 | 0.481 % | **13.8 %** | **13.7 %** | **10.7 %** |

- 全域解在原點 φ = 0° 上，Î₁ 於 θ ≈ 50°、310° 跳支（圖 `i1_f6_g_o_phi0.png`）；帶限制的解是連續的（`i1_f6_cmin_o_phi0.png`）。
- 帶限制的代價：原點上 η = ‖Î_opt‖ / ‖Î_cons‖ 最小 0.76，只有 43 % 的方向與全域解相同。

## 4. 可考慮的方向

1. **不用標籤**：直接用物理損失一步擬合（三角函數或 NN），由最佳化器自己找一組連續且力正確的解。要確認在含 bias 的模型下是否仍然成立，以及 λ‖Î‖² 讓解偏離最小電流多少。
2. **理解龍飛的限制**：找出 c_x、c_y、c_z 這組限制選中哪一支解、為什麼會連續，再看含 bias 時該怎麼推廣（門檻是否應隨 ê 改變）。
3. **連續延拓（homotopy）**：從無 bias 的平滑解出發，ê 由 0 漸增到實際值，每一步以前一步的解為初值，追蹤同一支解。
4. **標籤加平滑懲罰**：所有方向、位置的 Î_opt 一起求解，損失加上相鄰點差的平方，用平滑度換取最小電流。

## 5. 待決

- 「平滑」的判準（相鄰點 cos 門檻、或對方向的梯度上限）。
- 力誤差與 ‖Î‖ 的取捨可以接受到什麼程度（例如 η 的下限）。
- 驗證要用哪個力模型：龍飛模型、校正單參數、校正十八參數。
