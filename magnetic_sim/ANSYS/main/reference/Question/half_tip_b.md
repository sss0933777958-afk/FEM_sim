# 半圓柱尖錐磁極在極尖前的 |b| 為何比圓柱尖錐大

狀態：**待討論**（2026-11-22）。

## 1. 背景

單極模型（`D:\Maxwell_sim\Single_pole`）中：

- `cylinder_sharp_tip`：圓柱尖錐磁極，R40 µm 球尖，旋轉對稱
- `cylinder_half_sharp_tip`：將上者沿軸線剖半（只留 z ≤ 0），極軸落在剖面上

兩者的導磁塊、導磁柱、線圈（70 匝、1 A）、材料（µ_r = 280）、網格設定都相同。

在極尖前 0.01 mm 的空氣截面上找 |b| 最大的位置（`utils/scripts/Single_pole/peak_line.m`），兩者都在原極軸上 (y, z) = (0, 0)（20 µm 網格解析度）。

## 2. 問題

**半圓柱尖錐只有一半的磁極截面，為什麼在極尖前 0.01 mm 的 |b|（51.4 mT）反而比完整的圓柱尖錐（40.2 mT）大？**

## 3. 現有證據

沿極軸的場（模型座標，磁極本體在 +x，x ≤ 0 為空氣；mT）：

| x (mm) | sharp：b_x / b_y / b_z | sharp \|b\| | half：b_x / b_y / b_z | half \|b\| |
|---|---|---|---|---|
| −0.01 | −39.9 / 2.38 / −4.78 | 40.2 | −40.6 / 1.53 / −31.4 | 51.4 |
| −0.1 | −6.45 / −0.14 / 0.12 | 6.46 | −5.04 / −0.11 / 0.57 | 5.07 |
| −0.25 | −2.80 / −0.13 / 0.13 | 2.80 | −2.27 / −0.07 / 0.25 | 2.29 |
| −0.5 | −1.61 / −0.10 / 0.07 | 1.61 | −1.19 / −0.07 / 0.14 | 1.20 |
| −1 | −0.81 / −0.01 / 0.05 | 0.81 | −0.72 / −0.02 / 0.08 | 0.73 |

- 0.01 mm 處兩者 **b_x 幾乎相同**（−40.6 對 −39.9 mT），|b| 的差異幾乎全來自半切模型的 **b_z = −31.4 mT**：sqrt(40.6² + 31.4²) ≈ 51.3 mT
- 0.1 mm 以外，半切模型的 |b| 一律比較小（約 75–90 %），符合截面減半、磁通變少的直覺
- 其他相關數據：極尖（x = 0）的橫向場 |b_⊥| 由 N_c = 2 校正 RMS 反推，sharp ≈ 10 mT、half ≈ 66 mT；單磁荷擬合 ℓ̂ 為 53 / 37 µm，ĝ_c 為 56.4 / 63.7 mT（`single_pole_rms.md` 測試點版本）

## 4. 可考慮的方向

1. **剖面的稜角集中磁通**：極軸落在剖面與錐面的交線（尖端處是一條稜線）上，鐵件表面的尖角／稜線會使附近的場集中，且場垂直於剖面射出（b_z 大）。可檢查剖面上離極軸不同 y 的 b_z 分布，以及剖面在尖端附近的面磁通密度。
2. **極尖表面節點的影響**：0.01 mm 截面值是 x = −0.02 與 0 兩層節點的內插，x = 0 那層就是極尖表面，半個權重來自表面節點。改用沿極軸的線匯出、或在極尖局部加密（見 `single_pole_rms.md` §4），確認 51.4 mT 是否為網格造成。
3. **磁通總量對照**：比較兩者通過磁極某一截面（例如距尖端 1 mm）的總磁通 Φ。若半切的 Φ 明顯較小，而尖端 |b| 較大，即可確認是局部幾何（稜角）造成的集中，不是磁通變多。
