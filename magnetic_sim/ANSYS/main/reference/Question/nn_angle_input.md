# NN 以角度變量為輸入時的失真

狀態：**已測試**（2026-10-27）。

## 1. 背景

NN 反模型（物理損失）原本的輸入是 6 維：x = [r̂(φ, θ); p/45 µm]。
改成 5 維：x = [p/45 µm; φ/90; θ/180 − 1]，兩個角度正規化到 [−1, 1]；兩極 φ = ±90° 只取 θ = 0 那一筆。
其餘設定沿用 r̂ 輸入、seed 3、1000 回合的版本（15 µm 網格 343 點 × 5° 方向 2522 個、MB 1024、LR 1e-3 每回合衰減 0.99536、λ = 0.01、64-64）。

腳本：`matlab/Force/Maxwell/utils/scripts/long2016_hexapole_halfcut/nn_train.m`（`INP = 'ang'`）、`nn_net.m`（輸入個數 5）。

## 2. 結果

力誤差 e_f（平均 / 標準差，e_f > 1% 的比例）：

| 輸入 | T1 + T2 | T3 + T4 |
|---|---|---|
| 角度，最佳 seed 1 | 0.81% / 0.54%，23.6% | 0.89% / 0.78%，25.6% |
| 角度，seed 0、2、3 | 0.89% ~ 1.25% | 0.96% ~ 1.46%（seed 0、2 最大 > 120%） |
| r̂（seed 3） | 0.30% / 0.15%，0.17% | 0.29% / 0.15%，0.17% |

角度輸入四個 seed 都比 r̂ 輸入差約 3 倍；最終訓練損失 0.0014 ~ 0.0016，r̂ 輸入為 0.0012。

## 3. 誤差集中處（seed 1，T3，整體平均 0.91%）

| 方向範圍 | 平均 e_f |
|---|---|
| θ ∈ [350°, 360°) | 1.86% |
| θ ∈ [0°, 10°) | 1.16% |
| θ ∈ [30°, 330°) | 0.88% |
| \|φ\| ≥ 80° | 2.05% |

## 4. 原因

- **θ 的接縫**：θ = 355° 與 θ = 0° 在物理上相鄰，正規化後的輸入卻是 0.97 與 −1，網路須自行學出兩端相接。
- **兩極的奇異**：在 φ = ±90° 附近，θ 稍變方向幾乎不變，輸入卻變化很大；在極點上所有 θ 為同一方向。

r̂ 為連續的單位向量，沒有接縫，在極點也不奇異。
