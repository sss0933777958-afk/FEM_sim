# 雜訊對 flux 校正參數 ℓ̂、ê 的影響（待討論）

狀態：**問題已提出**（2026-10-13）。

## 1. 背景

目前 flux 校正是用 FEM 場值 b(p) 擬合電荷模型，得到 ℓ̂、ê（以及 ᴮĝ_I、K̄_I）。cost 是校正點上的殘差平方和：

J(ℓ̂, ê) = Σ ‖b(p) − b_model(p; ℓ̂, ê)‖²

FEM 資料沒有雜訊，所以擬合出的 ℓ̂、ê 沒有考慮雜訊。

## 2. 問題

實際量測會帶雜訊：b̃(p) = b(p) + n(p)。雜訊會讓 ℓ̂、ê 偏離無雜訊時的值。要怎麼分析雜訊對 ℓ̂、ê 的影響？

## 3. 老師的做法（待理解）

1. 先取無雜訊時的 ℓ̂（記為 ℓ̂₀）。
2. 讓 ℓ̂ 偏一點：ℓ̂ = ℓ̂₀ + δℓ。
3. 推出 J 與 δℓ 的關係。

**不懂的地方**：為什麼要這樣推？J 與 δℓ 的關係，怎麼對應到「雜訊造成 ℓ̂ 偏多少」？
