# 雜訊分析：一維電荷模型參數 a、b 的變異數（待辦）

狀態：**問題已定義、尚未執行**（2026-10-05）。待決項目見第 4 節。

## 1. 背景：單極一維退化模型

- 模型：NTU 單極（`config/NTU_hexapole/single_pole`），場來源 `D:\Maxwell_sim\NTU\export\single_pole\P1.fld`。
- 座標：原點＝極尖頂點（Maxwell 全域 (1.13064, 0, 0.125) mm），極軸 +x 指向極板內。
- 取樣：極尖往 −x 推 20 µm 起、每 20 µm 一點，共 17 點，x_i = −20, −40, …, −340 µm（帶負號進模型）。
- 資料：y_i = |b_x(x_i)| / I，I = 1 A（Maxwell 50 A·turn ÷ N_c 50）。
- 轉移函數：H(x) = a / (x − b)²，b＝電荷位置（沿 x，正值在極板內），a＝增益。
- cost：J(a, b) = Σᵢ (y_i − H(x_i))²。給定 b 時 a 有閉式解 a*(b) = Σ(y_i u_i) / Σu_i²，u_i = 1/(x_i − b)²；對 b 一維最小化。

擬合結果（無雜訊）：

| b | a | cost | RMS |
|---|---|---|---|
| 103.49 µm | 1.3347 mT·mm²/A | 144.9 (mT/A)² | 2.92 mT/A |

profile cost J(b)（每個 b 重算 a）在 b = 77.4 ~ 138.0 µm 內不超過最小值兩倍；若固定 a，此範圍只有 97.6 ~ 110.3 µm。

## 2. 問題

在 17 個 FEM 值上加入雜訊後，a、b 的變異數（標準差）各是多少？a、b 的相關性多大？

## 3. 建議方法：蒙地卡羅

1. 每點加獨立高斯雜訊：ỹ_i = y_i + n_i，n_i ~ N(0, σ_i²)。
2. 每組 ỹ 用同一套方法重新擬合（閉式 a + 對 b 一維最小化）。
3. 重複約 10,000 次，統計 a、b 的平均、標準差、相關係數，並畫直方圖。

線性化預估（可用來檢查蒙地卡羅程式；小 σ 時兩者應一致）：每點 σ = 1 mT/A 時

| | 標準差 |
|---|---|
| b（a、b 一起擬合） | ≈ 2.30 µm |
| b（a 固定） | ≈ 0.52 µm |
| a | ≈ 0.042 mT·mm²/A（約 3.1%） |

a、b 相關係數 ≈ 0.974。標準差與 σ 成正比；σ 變大後蒙地卡羅會偏離線性化，那是非線性效應出現的地方。

## 4. 待決

- **雜訊型態**：
  - 絕對雜訊（每點同一 σ，mT/A）：像 Hall sensor 量測雜訊；遠端點訊號只有約 9.5 mT/A，受影響最大。
  - 相對雜訊（σ_i = p% × y_i）：像增益或校正誤差；近端點受影響最大。
- **雜訊大小**：若無實際量測雜訊值，先掃幾個等級（例如絕對 σ = 0.1、0.5、1、2 mT/A）。
- 是否也對 NTU 對極（P1 激發）做同樣分析。

## 5. 注意

- 蒙地卡羅只量雜訊造成的**分散**，不量模型誤差。無雜訊時的殘差（RMS 2.92 mT/A）是 1/(x − b)² 形狀配不上 FEM 的系統誤差（FEM 衰減比 1/r² 慢），不是雜訊；b 會以 103.5 µm 為中心散開，但不代表 103.5 µm 本身正確。
- a、b 高度相關，評估 b 的準確度必須讓 a 一起重擬（profile），不可固定 a，否則會低估 b 的分散約 4~5 倍。
